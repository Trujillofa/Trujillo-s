## 🧭 How I build

1. **Ship for production first** — observability, safe deploy paths, and rollback habits over demo-only code.
2. **Automate the boring path** — agents, scripts, and scheduled jobs for ops and analysis.
3. **Measure before you trust** — backtests, paper trading, and business metrics before live risk.
4. **Keep the stack lean** — clear modules, explicit config, no mystery credentials in git.
